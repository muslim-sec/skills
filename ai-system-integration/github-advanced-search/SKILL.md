# GitHub Advanced Search Skill

Use this skill to find exact code snippets or niche repositories across all of GitHub.

## Search Strategies
1. **Precise Code Search**: Formulate advanced queries targeting specific APIs (e.g., `import supabase-js language:typescript`).
2. **Topic & Star Filtering**: Filter searches by `topic:svelte` or `stars:>500` to weed out low-quality results.
3. **Repo Deep-Dive**: Once a candidate repo is found, immediately fetch its README to verify relevance before reading source files.

## Guidelines
- Avoid generic searches. Always combine keywords with language and topic modifiers for precision.
- If the first query fails, iteratively broaden or narrow the search parameters.
