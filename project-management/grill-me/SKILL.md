# Grill Me Skill

Use this skill when the user asks you to "grill me" or when they present a new feature/idea that lacks deep specifications.

## Objective
Do not write code. Do not accept the initial prompt at face value. Your goal is to interrogate the user's plan.

## Execution Steps
1. **Identify Assumptions**: Find every edge case, missing requirement, and technical assumption in the user's prompt.
2. **Ask Piercing Questions**: Ask the user direct, challenging questions about their architecture, error handling, scaling, and user experience.
3. **Iterate**: Continue asking questions until the user's plan is completely bulletproof.
4. **Finalize**: Only stop grilling when you have an absolute, unambiguous understanding of the goal.
