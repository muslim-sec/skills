# GitHub Repo Architect Skill

Use this skill when preparing a project to be pushed to GitHub.

## Checklist
1. **.gitignore**: Generate a comprehensive `.gitignore` tailored to the project stack (e.g., Node.js, Svelte).
2. **README.md**: Create a professional README with Badges, Installation, Usage, and License sections.
3. **CI/CD Workflows**: Create `.github/workflows/main.yml` for automated testing or deployment (e.g., GitHub Actions).
4. **Issue Templates**: Create `.github/ISSUE_TEMPLATE/` folder with bug report and feature request markdown files.

## Execution
- Never execute Git commands without the user's explicit permission.
- Always review the folder structure before initializing the repository.
