# Data Visualization Architect

## Overview
This skill does not draw the final charts; it is the strategic planner that decides *how* data should be visualized to achieve maximum impact on the reader.

## Workflow
1. **Review Analytics**: Read the insights generated by `security-data-analyst`.
2. **Select Visual Medium**:
   - *Proportions/Severity*: Recommend Python-generated Pie/Bar charts.
   - *Network Architecture*: Recommend Excalidraw diagrams.
   - *Attack Chains/Logic*: Recommend Mermaid flowcharts or sequence diagrams.
   - *Data Density*: Recommend Heatmaps.
3. **Draft Visual Spec**: Create a specific prompt/blueprint for each visual (e.g., "Create a Mermaid flowchart with 4 nodes showing the SQLi to RCE chain").
4. **Delegate**: Pass these blueprints to `python-chart-generator` or use built-in diagram tools.

## Rules
- Avoid visual clutter. Do not recommend a chart if a simple table is more readable.
