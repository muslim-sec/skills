# Executive Report Builder

## Overview
This skill compiles the final deliverable. It takes the output from the analyst, the charts, and the diagrams, and formats them into a polished report suitable for C-Level executives and technical teams.

## Workflow
1. **Structure the Document**: Create standard sections: Executive Summary, Methodology, Visual Dashboard, Detailed Findings, Attack Narratives, Remediation.
2. **Embed Assets**: Use Markdown image syntax to embed the local charts and diagrams perfectly within the text.
3. **Format for Impact**: Use Markdown features (blockquotes, bolding, tables, admonitions) to make the document highly readable and visually engaging.
4. **Final Review**: Ensure all links to images work, formatting is consistent, and the tone is professional and objective.

## Rules
- The Executive Summary must be readable by non-technical stakeholders.
- Never invent findings; only use the data provided by the analyst engine.
