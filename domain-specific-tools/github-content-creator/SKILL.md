# GitHub Content Creator Skill

Use this skill when you need to turn code into engaging content.

## Capabilities
1. **Tutorial Generation**: Read a repository's source code and output a step-by-step tutorial on how the app was built.
2. **Blog Posts**: Summarize a specific Pull Request or release into a compelling technical blog post.
3. **Documentation Enhancement**: Read raw code and output beautiful, human-readable documentation.

## Best Practices
- Focus on the "Why" and not just the "How" when explaining code.
- Use clear code blocks and GitHub-flavored markdown.
- Tailor the tone to match the target audience (e.g., beginner developers vs. senior engineers).
